# 🛡️ Azura Time

Autonomous attendance & face recognition app for Indonesian education ecosystem.

## ✨ Key Features
- 📸 Face-based attendance with Azura Engine
- 🔄 **Autonomous In-App Update** (no Play Store dependency for emergency fixes)
- 🔐 SHA256 integrity verification before install
- 💾 Zero data loss on update (Room DB + Preferences intact)
- 🌐 Hybrid fallback: Firebase Remote Config → GitHub Pages
